# 동네 가전 대여 (테스트용 프로토타입)

동네 이웃끼리 자주 쓰지 않는 소형 가전이나, 사기 전에 써보고 싶은 고가 전자기기
(청소기류, 주방 가전, 뷰티·헬스)를 빌리고 빌려주는 앱의 프로토타입입니다.
당근 [SEED Design](https://github.com/daangn/seed-design) 컴포넌트로 만들었습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저를 휴대폰 크기로 줄이거나, 데스크톱에서는 가운데 430px 폭으로 보입니다.

## 화면 흐름

상품 목록 → 상품 상세 → 대여 날짜 선택 → (결제 생략) → 예약 완료 → 채팅

| 화면 | 내용 |
| --- | --- |
| 상품 목록 | 상품명, 브랜드, 대여자 닉네임, 대여 가능 날짜, 1일 가격 / 카테고리 필터 |
| 상품 상세 | 사진 캐러셀, 대여자 닉네임 + 매너온도, 제품명 + 설명 2줄, 브랜드, 구매시기 |
| 대여 날짜 | ① 받는 날 → ② 대여 기간(1일·3일·5일·1주일) → ③ 받는 방법(가지러 가기: 받는 시간 / 택배로 받기: 배송지) → 반납 일정 자동 계산 → 금액 |
| 예약 완료 | 제품명, 대여 날짜·시간, 대여 기간, 받는 방법, 대여 가격, 택배비, 보증금, 결제 금액, 수락 상태 |
| 채팅 | 대여자와 대화, 예약 내용 카드, 대여자 수락 알림 |

## 규칙

- **대여 기간**: 1일 / 3일 / 5일 / 1주일 중 선택 (최대 7일). 기간별 가격은 상품마다 `src/data/products.ts`의 `prices`에 있습니다.
- **금액**: 기간 가격 + 왕복 택배비(택배로 받을 때 6,000원) + 보증금
- **수량**: 항상 1개
- **이미 예약된 날짜·시간은 선택 불가**: 반납 시간까지 다른 예약과 겹치면 막습니다. 택배는 받는 날 오전 9시 도착 기준으로 계산합니다.
- **예약 확정**: 예약 요청 → 대여자 수락 → 확정. 데모에서는 채팅방에 들어가면 대여자가 자동으로 수락합니다.

## 참고

- 서버 없이 `src/data/products.ts`의 가짜 데이터로 동작합니다. 예약과 채팅은 탭을 닫으면 사라집니다.
- 상품 사진은 [Unsplash](https://unsplash.com/license)의 무료 사진을 주소로 불러옵니다 (`src/data/products.ts`의 `photos`). 실제 상품 사진이 생기면 이 값만 바꾸면 됩니다.
- SEED에 없는 **이미지 캐러셀**과 **채팅 말풍선**은 SEED 색상·간격 토큰으로 직접 만들었습니다 (`src/index.css`).
- SEED Time Picker는 특정 시간을 막을 수 없어서, 받는 시간은 SEED Chip(라디오)으로 고르게 했습니다.
- `seed-design/ui/*`는 `npx @seed-design/cli add`로 받은 스니펫입니다. Stackflow 2.x에 맞춰 `app-bar.tsx`, `app-screen.tsx`의 `useActions`를 `useFlow`로 바꿨습니다.
